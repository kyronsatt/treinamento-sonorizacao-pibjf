# Treinamento de Sonorização — PIBJF Cidade Alta

Manual interativo para operar a mesa **Duonn Axios 24**, resolver problemas reais de áudio e cuidar do áudio da transmissão (Axios 24 → Reaper → OBS).

## Deploy

Hospedado na Vercel. Página 100% estática (HTML/CSS/JS único arquivo).

## Desenvolvimento

Abra `index.html` em qualquer navegador, ou:

```bash
python3 -m http.server 8000
```
